# 开发数据库快照

本目录的 `.sql` 和 `.csv` 文件仅用于本地调试、数据结构对照或受控的数据迁移开发。

- 禁止将这些快照导入生产数据库。
- 生产环境通过 `aerich upgrade` 创建或升级结构，并仅在首次初始化时启用最小种子（角色、权限、初始管理员）。
- 任何已有产品、新闻、分类、询盘和上传记录都必须通过受控备份恢复或业务迁移保留，不能依赖本目录快照覆盖。
- 若仓库需要公开发布，应另行制定敏感历史清理方案；本次不改写 Git 历史。
