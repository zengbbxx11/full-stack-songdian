## 本轮实际修复

- 首页分类展示原先以短 slug 查完整 slug 配置键，导致说明缺失；分类经过过滤后又用位置匹配元信息，存在错配隐患。改为分类与文案共同映射，并保留缺省回退。
- 轮播非法槽位不再被删除而导致后续图片顶替首图；异常图片 URL 被拒绝；默认桌面图回退时保留已配置的移动图。
- 媒体使用统计覆盖首页轮播桌面图和移动图（含已保存但暂未启用的槽位），普通删除会返回引用冲突，沿用原有显式强制删除机制。
- 后台媒体引用类型补齐产品正文、新闻正文和首页轮播；新闻正文进入新闻编辑页，轮播进入设置页。
- 图片选择器明确拒绝视频，避免浏览器文件选择框的“所有文件”绕过 accept 提示，把视频当封面或正文图片。
- 后端单元测试隔离本机 NEXT_REVALIDATE_URL，避免初始化夹具请求真实官网并留下重试任务。未修改生产刷新逻辑。
- 修复追踪测试脚本的模块加载器，使新增的 API client import 能被执行。

## UI / UX 与性能

- 首页产品区改为稳定的响应式网格，图片使用 object-contain，分类说明和入口持续可见；复用 SafeImage 提供失败占位。
- 复用现有 SOLUTIONS 数据新增 OEM/ODM 合作方式入口，没有新增数据源或营销数字。
- 调整 Hero 标题大小、行高、内边距和矮屏最小高度；对齐首屏骨架高度，减少布局跳动。
- 修复 Cookie 提示出现时轮播指示点被抬到 CTA 上的重叠；独立跟踪键盘焦点和鼠标悬停暂停状态。
- 轮播离屏或页面隐藏时暂停自动切图，保留首图优先加载、其他图首次访问才挂载的策略；移除整页 DOM MutationObserver。
- 首页更多链接显式关闭预取，修正产品图 sizes；底部询盘 CTA 提高文字对比度，明确询盘可提供的信息。
- 没有新增依赖、图片资源或复杂动画。未改变 API 路径、数据库结构和现有发布流程。
