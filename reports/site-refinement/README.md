# 官网整体视觉与交互优化

## 范围与分析

整体检查首页、产品列表/详情、解决方案、关于、新闻、联系及 FAQ。文案、产品资料和核心页面结构保持现状。原导航、时间线、证书图库与表单已具备交互，本轮保留其成熟行为，重点改善重复排版和缺失的图片键盘操作。

## 本轮变化

- 首页新闻：桌面采用一张主卡 + 两张紧凑横向卡，平板主卡独占一行，手机自然纵排；保留原新闻标题、摘要、日期和图片。
- 解决方案：三段内容增加装饰编号，桌面交替排列概述与要点；要点区域增加轻底色和分隔；移动端维持原 DOM 阅读顺序，减小不必要的内边距。
- 关于：工厂能力改用分隔线建立横向信息节奏，保留工厂视频、时间线和证书原有交互。
- 联系：联系方式之间增加分隔、长邮箱允许换行、表单焦点采用轻背景反馈。
- 数字：保持真实最终值与 SSR 内容，只加入进入视口时轻微位移/缩放强调，不从零累加经营事实。
- 产品图库：方向键、Home/End 可选择与聚焦缩略图；切换图片加载完成后使用 240ms 原生淡入/轻缩放，首图不触发该动画。
- 新闻卡片：聚焦与 hover 的标题反馈一致，限制动画属性，日期信息提高对比度。
- 页面动效：区分纯淡入、轻位移与数字强调，CSS view timeline 不依赖 JS 滚动监听；不支持时静态展示。保持减少动态、打印下的内容可读性。

## 验证

- 官网 ESLint、TypeScript、生产 build 通过（67 页静态生成）。
- 首页布局、API 映射和新闻产品内链共 15 条回归通过。
- SEO/GEO 静态检查通过。
- 首页、产品、解决方案、关于、新闻、联系、FAQ 在 390/768/1440 宽度共 21 组浏览器检查：无横向溢出、每页单个 H1、无 pageerror。
- 320px 联系页无横向溢出；真实产品详情图库 ArrowDown/End/Home 操作通过。
- 减少动态模式下方案动画为 none、opacity 为 1。
- 桌面/手机截图位于本目录，文件名 home/solutions/about/contact-390/1440.png。长截图中的屏外区域可能处于 CSS 入场起始状态，实际滚入时呈现终态。

## 限制

没有新增依赖，没有修改 API/数据库；未执行完整 Lighthouse 或全量后端/E2E。CSS view timeline 不支持的浏览器采用静态呈现。localhost:3102 为开发预览，使用已有的仅开发本地图片优化开关；生产限制不变。现有本地库有此前测试内容，本轮未修改业务记录。
